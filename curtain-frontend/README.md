# Curtain Store

A modern, responsive static e-commerce website for browsing and purchasing curtains, built with **React** and **Vite**. The project demonstrates a complete frontend shopping experience, including product browsing, authentication UI, cart management, checkout, payment simulation, and order confirmation.

---

## Features

### Product Catalog

* Browse a collection of curtain products
* Product details page
* Product search
* Product categories
* Product ratings
* Responsive product cards

### Shopping Experience

* Add products to cart
* Update item quantities
* Remove items from cart
* Wishlist functionality
* Order summary
* Shipping information form

### Authentication (Static)

* Login page
* Register page
* Forgot password page
* Protected routes
* User profile
* Persistent login using localStorage

### Checkout & Payment

* Shipping details form
* Payment method selection
* M-Pesa payment simulation
* Card payment simulation
* Cash on Delivery option
* Order confirmation page
* Order history stored in localStorage

### User Interface

* Fully responsive layout
* Modern navigation bar
* Cart sidebar
* Loading states
* Password strength indicator
* Clean and reusable React components

## Installation

Clone the repository:

```bash
git clone https://github.com/Papa-Nolito/curtain-store.git
```

Move into the project folder:

```bash
cd curtain-store
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
